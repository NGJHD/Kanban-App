# kanban-app

Vibe coded this kanban app to my own liking. Why don't I use an existing one? I think they have too many features. Too many for my caveman brain to use.

<img width="1902" height="752" alt="Kanban" src="https://github.com/user-attachments/assets/a45072ab-372d-45ec-be40-82a9690646d2" />

Features
- Double click on the grey part of the column to add a card
- There is no title for the card, only description.
- Markdown supported in the description
- Click the priority dropdown button to change priority immediately
- Drag and drop between columns
- Everything saves to a local JSON file
- When you drag to completed, a completed date will be assigned automatically
- You can sort by priority or by date
- There is a search (filter) button that filters the entire board
